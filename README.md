# Arthur Milander — Portfolio

Personal portfolio for Arthur Milander, bringing together selected projects, learning experiences, recognition, and an evolving space for experiments.

**Website:** [square-cpu.github.io](https://square-cpu.github.io/)

## Built with

- **Astro 7** for statically generated pages and Content Collections
- **TypeScript** for typed content and application code
- **CSS** for responsive layouts and a shared design-token system
- **Vanilla JavaScript** for focused interactions and accessible navigation

Typography uses self-hosted Instrument Sans and IBM Plex Mono.

## Run locally

Use Node.js 22.12 or later; Node 24 is recommended.

```sh
npm ci
npm run dev
```

Open `http://localhost:4321`.
